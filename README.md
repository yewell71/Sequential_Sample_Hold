# Sequential_Sample_Hold
Open Source Eurorack Synthesizer Module

This project is a four-channel sample-and-hold circuit for modular Eurorack synthesizers.

Basic function: One input is sampled and sequentially stored at one of four ouputs.
If two to four VCOs are controlled using this module, interesting polyphonic patterns are generated.
This greatly expands the capability of the traditional sample-and-hold module.
The project includes schematic and Gerber files.  There is also a CAD file for a front-panel design.

An article on the Sequential Sample & Hold will be published soon.
This is an on going project that will include many "patch" ideas.
